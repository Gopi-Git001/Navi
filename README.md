# Navi

Navi is a voice-driven computer assistant.

## Layout

- `docs/` — product plan, technical spec, tool contract, benchmarks, command script, and safety rules
- `reference/` — read-only reference materials
- `voice/` — voice capture, speech recognition, and speech synthesis
- `browser/` — browser control
- `agent/` — the assistant loop that turns commands into actions
- `research/` — notes and experiments
- `tests/` — automated tests
- `benchmarks/` — benchmark harness and recorded results
- `test_audio/` — audio fixtures for voice and command tests
